# Арман | Разработка цифровых продуктов

Занимаюсь созданием и развитием собственных IT-проектов. Работаю над проектированием функциональности, организацией разработки, тестированием и последовательным улучшением продуктов.

## Проекты

### Earth2150Remake — стратегия в реальном времени

Проект RTS-игры на Unity и C#, вдохновлённый классическими стратегиями серии Earth 2150.

Основные направления разработки:

- Игровая экономика и система ресурсов.
- Производство техники и управление энергоснабжением.
- Перемещение юнитов и поиск пути.
- Архитектура игровой симуляции и автоматизированное тестирование.

**Статус:** активная разработка. Исходный код находится в приватном репозитории. Публичная демонстрация проекта готовится.

### SGQS — приложение

Собственный программный проект, прошедший этап создания бета-версии и тестирования с участием первых пользователей.

Работа включает развитие функциональности, проверку поведения приложения и исправление обнаруженных проблем.

**Статус:** бета-версия. Подробное описание и демонстрация будут добавлены отдельно.

### Telegram Mini App

Проект мини-приложения для экосистемы Telegram.

**Статус:** материалы для публичного представления подготавливаются.
