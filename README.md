# Арман Тахмазян | Разработка приложений

Развиваю собственные проекты для Windows, веба и Unity. Занимаюсь проектированием функциональности, пользовательскими сценариями, архитектурой, тестированием и последовательным улучшением продуктов.

## Проекты

### [SGQuietSentinel (SGQS)](https://github.com/armanfightman/SGQuietSentinel-Showcase)
**Windows · C# · .NET 8 · WinUI 3**

Приложение для локального мониторинга CPU, GPU, памяти, дисков и процессов, а также разбора системной нагрузки. В проекте реализованы интерфейс, сбор показателей через Windows API и автоматизированные тесты.

**Статус:** активная разработка. Обычная сборка и основные экраны проверены; релизная приёмка пока не завершена. [Скриншоты и техническое описание](https://github.com/armanfightman/SGQuietSentinel-Showcase).

### [VORS — Telegram Mini App](https://github.com/armanfightman/VORS-Showcase)
**Next.js · React · TypeScript · Node.js**

Мини-приложение для индивидуальных ковров: мобильный интерфейс, форма заявки из шести шагов, резюме перед отправкой и экран проверки статуса. В коде предусмотрены серверные обработчики, интеграция с Supabase и Telegram-ботом.

**Статус:** MVP в разработке. Проверены локальные сборки и сценарии интерфейса; сквозная работа с внешними сервисами ещё требует проверки. [Интерфейс и архитектура](https://github.com/armanfightman/VORS-Showcase).

### Earth2150Remake — технический прототип RTS
**Unity · C#**

Работа над основой стратегии в реальном времени: игровой экономикой, производством, энергоснабжением, перемещением юнитов и архитектурой симуляции.

**Статус:** ранняя стадия разработки, тестовые сцены Unity. Исходный код пока находится в приватном репозитории.

## Технологии и инструменты

`C#` · `.NET 8` · `WinUI 3` · `Unity` · `TypeScript` · `Next.js` · `React` · `Node.js` · `Git` · `GitHub` · `MSTest`

## Подход к работе

Разделяю разработку на проверяемые этапы, фиксирую изменения в Git, использую тесты и документирую ограничения текущих версий. Публичные страницы проектов содержат демонстрационные материалы; рабочие репозитории с исходным кодом остаются приватными.
